# Mailtric CLI

Official Command-Line Interface for [Mailtric](https://github.com/Mailtric).

[![npm version](https://img.shields.io/npm/v/mailtric.svg)](https://www.npmjs.com/package/mailtric)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## Installation

You can run `mailtric` directly using `npx`:

```bash
npx mailtric
```

Or install it globally via `npm`:

```bash
npm install -g mailtric
```

## Usage

```bash
# Run default command
mailtric

# Greet a specific user
mailtric hello "Alice"

# Display version
mailtric --version

# Display help
mailtric --help
```

## Options & Flags

| Option | Shorthand | Description |
| --- | --- | --- |
| `--help` | `-h` | Show help and available commands |
| `--version` | `-v` | Display the installed version |
